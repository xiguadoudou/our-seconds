# 豆豆 × 喵喵 · 我们的每一秒

从 2026 年 3 月 24 日 00:00（北京时间）开始，记录我们的每一秒。

静态纪念页，包含毫秒计时、日夜主题、情书、周年与生日倒计时，适配手机和电脑。

## 日期与文案

编辑 `config.js` 可修改所有访客看到的默认日期、称呼与情书。页面底部的纪念日设置仅保存在当前浏览器，也可以下载包含新设置的独立网页。

- 豆豆生日：2003-10-29。
- 喵喵生日：2006-10-10。
- 生日与周年按北京时间计算；生日当天显示祝福。
- 计时依据当前设备时间，关闭后再打开仍计算完整经过时长，显示三位毫秒；画面约每 32 ms 更新一次。

## 手机布局

背景装饰位于独立的裁切容器，不会撑宽页面。手机页面取消预留滚动条空隙，并限制横向溢出。弹窗按可视区域居中，关闭后恢复原来的滚动位置。生日区保留 DOM，仅更新变化的数值。

已检查 320、390、430 像素宽度，页面没有额外的横向滚动范围。

## GitHub Pages

Settings → Pages → Source: Deploy from a branch → main / (root) → Save。

纯 HTML、CSS 与 JavaScript，不需要后端或第三方服务。


## 小彩蛋

- 长按名字约 0.65 秒，让两个人贴近；再次长按松开。上下滑动会取消长按，不阻挡页面滚动；键盘 Enter/空格也可操作。
- 点击「两个人，把日子过成诗」，文字会轻轻起伏，并出现一句小情话。
- 点生日卡片的小星星，为对方许一个愿。
- 页尾的小心心藏着多次点击的小惊喜；切换到夜间也会划过一颗小流星。
- 增加细线爱心、星光、手写下划线与纸笺装饰。

动效使用 transform 与 opacity；诗句离开屏幕即暂停，后台页面停止装饰动画。粒子有数量限制并自动回收，尊重系统「减少动态效果」偏好。装饰和粒子均裁切在独立容器内，不增加横向滚动范围。
