# 豆豆 × 喵喵 · 我们的每一秒

从 2026 年 3 月 24 日 13:00（北京时间）开始，记录我们的每一秒。

浪漫纪念页，支持天数与毫秒计时、日夜主题、情书、周年倒计时、手机布局。

## GitHub Pages

Settings → Pages → Source: Deploy from a branch → main / (root) → Save。

## 修改内容

编辑 `config.js` 可以更改所有访客看到的称呼、纪念日和情书。页面里的设置保存在当前浏览器；「下载专属页面」可导出包含新设置的独立网页。

开始时间使用明确的 `+08:00` 时区。计时通过当前设备时间减去开始时间计算，显示三位毫秒数，画面按屏幕刷新率更新。

本页不依赖第三方图片、字体、脚本或后端服务。


## 生日与照片

- 豆豆：2003-10-29；喵喵：2006-10-10。按北京时间计算，生日当天展示祝福，平时倒计时到下一次生日。
- 图集支持照片错落叠放、左右滑动、箭头与键盘翻页、点击查看完整原图。
- 页面添加的照片通过 IndexedDB 保存在当前浏览器，不会自动同步给其他访客。支持编辑标题和移除本地照片。
- 两个人都能看到的共享照片：将原图放进 photos/，在 config.js 的 photos 数组配置 src 与 caption；不压缩原图。
- 手机弹窗按 VisualViewport 居中；320px 与 390px 预览中均无横向溢出。
