# 豆豆 × 喵喵 · 我们的每一秒

从 2026 年 3 月 24 日 13:00（北京时间）开始，记录我们的每一秒。

静态纪念页：毫秒计时、日夜主题、情书、周年与生日倒计时，以及错落叠放的滑动图集。

## 直接上传到共享相册

1. 在网页中点击「连接共享相册」。
2. 去 GitHub 创建 Fine-grained personal access token，Repository access 只选择 `our-seconds`；Repository permissions 的 **Contents** 选择 **Read and write**，设置到期时间。
3. 返回网页，将令牌填进相册连接窗口。只在本次页面内存中保留，刷新或关闭后需重新连接；不要把令牌发到聊天、填入 config.js 或提交到仓库。
4. 点击「添加照片」，在系统选图器中选择原图，检查标题后点击「上传到共享相册」。
5. GitHub Pages 会自动发布更新。其他设备打开网页或点击「刷新共享相册」即可查看；部署期间可能需要稍等。
6. 之前仅保存在本机的照片，可以通过「整理照片 → 上传本机照片到共享相册」补传。

照片以原始字节存入 `photos/`，相册列表记录在 `photos.json`。仓库公开，上传的共享照片可被其他访客查看。每批最多 20 张，单张最多 25 MB。网页不内置公共上传凭据，没有令牌的访客不能向仓库写入。

上传采用 Git blobs → tree → commit → 非强制更新 main 的方式，将一批原图和相册列表一起发布。遇到并发修改会重新合并最新相册；不会强制覆盖其他提交。网络在保存时中断，会先检查是否已成功发布。

GitHub 官方权限说明：https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens

## 本机预览与离线导出

选择照片后也可点「仅在本机预览」，照片通过 IndexedDB 保存在当前浏览器。可以修改标题、移除本机照片，或稍后补传。原系统相册中的文件不受影响。「下载专属页面」可以导出当前纪念日设置和照片；导出文件不包含令牌。

## 日期与文案

编辑 `config.js` 可修改所有访客看到的默认日期、称呼与情书。页面底部的纪念日设置仅保存在当前浏览器。

- 豆豆生日：2003-10-29。
- 喵喵生日：2006-10-10。
- 生日与周年按北京时间计算；生日当天显示祝福。
- 计时依据当前设备时间，关闭后再打开仍计算完整经过时长，显示三位毫秒；画面约每 32 ms 更新一次。

## 手机兼容

选图入口是可直接触摸的原生文件控件，无需脚本触发隐藏 input。弹窗保持背景滚动位置，关闭后恢复；生日数字与照片卡片保留 DOM，避免反复重建导致失焦与滚动锚定。普通页面滚动不再触发 VisualViewport 全页重排。
